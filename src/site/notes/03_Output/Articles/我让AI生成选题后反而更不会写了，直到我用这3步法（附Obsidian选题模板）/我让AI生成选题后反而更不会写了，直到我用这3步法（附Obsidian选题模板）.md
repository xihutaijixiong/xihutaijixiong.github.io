# 标题：我让AI生成选题后反而更不会写了，直到我用这3步法（附Obsidian选题模板）
对于需要创作输出的人，是否有和我一样，会遇到创作选题困扰，过去遇到这个问题，我尝试搭建了一个选题框架，比如：

>领域主题+分析维度=选题

的基础结构来设定选题，类似：Obsidian工作流、QuickAdd自动化案例。这些选题没有问题，但是不知道为什么，基于功能、基于工作流，即使已经有研究探索过的内容，一到写作输出环节，有一股无形的阻力让我停下来。

## 原因分析

对于有明确插件也好，功能也好，基于这种目的去创作，在思维上是处于被动创作，无法带来创作价值上的动力。

虽然有框架和明确的写作主题，甚至AI也可以建议选题，但是它存在一个非常明显的缺陷，**选题可以无限，但是确不能决定”我到底想不想写“。** 这可能也和很多创作新手无法开启创作的原因。

当你拿着框架组合的选题，和AI给的选题，不知道为什么要写这个选题，你可能在犹豫：

1. 这个选题有价值吗？
2. 这个选题好像没什么特别的？
3. 这个选题我熟悉吗？
4. 这个选题我专业吗，会不会写出来太easy了？

大脑各种劝退思想，对于不敢下手的人，一定要先写，无论写成什么样，但是对于敢于下手的人，但是还在犹豫，我想告诉你，你已经进入一个对写作有更高要求的状态了。

你在考虑为什么而写？只是没有形成写作的冲动，写作冲动一般来源于：

1. 我发现了一个东西：”好东西，值得分享“
2. 我解决了一个问题：”这个问题困扰我很久，终于解决了。”，这也是为什么最近分享Obsidian工作台内容，因为这个集合工作台终于解决了我任务管理、项目管理、内容管理分散管理的问题
3. 我产生了一个判断：“我现在和以前看法不一样了”，这也是我写这篇内容的原因，这篇并不是一个插件功能，也不是一个高端工作流分享，但是我终于找到选题困难的原因和办法了，因此，迫切的希望分享出来，希望对和我有一样问题的人可以有共鸣和帮助。

AI给出的选题更多是集合了后台数据，输出的是大部分可能感兴趣的选题，并不等于你想写的选题内容。

## 解决方案

建立一个问题库，通过AI结合主题框架来给出有价值的选题，然后再给自己建立一个选题过滤标准，经过这几轮的转化，你会发现很多你非常有动力去写的选题。

>问题库+AI+框架+过滤标准=选题

## 详细步骤

### 1、建立问题库

对于问题库，主要聚焦以下3个问题来记录：

1. 记录我最近遇到的问题
2. 我最近发现什么异常现象
3. 我最近改变了什么看法

举例：
```Markdown
1、记录我最近遇到的问题

（1）笔记越来越多，如何快速找到我想找的笔记、项目、一些没有标题也没有打标的笔记（搜索插件解决不了，不记得关键词，只是记得属于一个AI的回答中的一个举例，根本无法找到）
... ...

2、我最近发现什么异常现象

（1）AI分析105本读书笔记，我发现自己可能一直在重复学习
（2）我把我的职业经历建立成数据资产交给AI，发现了自己隐藏的5个能力（这也是我一直在通过AI挖掘个人数据资产价值，找到让自己可以发现自己问题、优势、行动方向和建议的，成长最快方法）
... ...

3、我最近改变了什么看法

(1) 以前觉得插件越多越强，现在发现插件越少反而更适合自己
(2) 以前觉得选题靠输入，靠学习新功能，现在才发现一定要积累问题，从问题出发
... ...

```

## 2、AI+框架分类衍生

定期每周让AI整理，直接提供本周问题，然后给出以下要求：

```
将本周的问题、发现和改变按照Obsidian、AI实验、行业、个人认知分类，并寻找其中具有内容价值的变化，给出建议选题。
```

AI分析输出：

|分类|本周素材|表面问题|更深层的内容价值|
|---|---|---|---|
|**Obsidian**|笔记越来越多，越来越难找|如何搜索笔记|**传统搜索为什么正在失效？知识库规模变大后，检索方式是否应该改变？**|
|**Obsidian**|无标题、无标签、记不起关键词的笔记|搜索插件找不到|**人记住的往往不是关键词，而是“语义、场景和当时的问题”**|
|**AI实验**|AI分析105本读书笔记|读了很多书|**大量输入可能只是重复确认，而不是认知增长**|
|**AI实验**|职业经历建立成数据资产|梳理职业经历|**个人数据中可能存在自己没有意识到的能力模式**|
|**AI实验**|用AI挖掘个人数据资产|AI帮自己分析|**AI真正的价值可能不是给答案，而是帮助人发现自己看不见的东西**|
|**个人认知**|插件越多越强 → 插件越少越适合自己|工具取舍|**复杂系统不一定带来更高效率，系统应该服务于行为**|
|**个人认知**|选题靠输入 → 选题应该从问题出发|内容生产|**真正持续的选题来源不是“学到了什么”，而是“我遇到了什么问题”**|
|**行业**|AI + 个人数据资产|AI应用|**AI正在从“知识问答工具”转向“个人认知分析器”**|

可见，AI的总结分析和拓展能力是比人要更高效和完整的，从AI分析可以进一步加入自己的判断，就可以找到自己最有动力创作的内容选题了。

比如如下几个选题：

1. AI分析105本读书笔记后，我发现自己可能一直在重复学习
2. 我把职业经历交给AI后，发现了5个自己一直没意识到的能力
3. 笔记超过一定数量后，搜索可能正在失效：我开始重新思考Obsidian的检索方式
4. ... ...

## 3、过滤5问

AI会 给出很多建议的标题，最终依旧要通过人来进行判断，因此，必须要结合自己的情况，建立一个过滤器，提高选题的效率。建议按照如下5个问题进行过滤思考：

1. 我自己真的遇到过吗？：不以AI给的话题热度为标准
2. 我有没有产生过变化？：自己实验确认过的有用的方法
3. 我有没有一手数据/实验/实践？自己是否有沉淀素材和内容输出
4. 我有没有自己的判断？：不要AI告诉你怎样就怎样，而是我实践以后，我认为有没有价值
5. 用户获得什么？：不能仅仅自己觉得有用，从用户角度是否有收获方法、工作流、认知、经验等

## 总结

对于创作过程中，既要主动思考，又要学会用AI来放大价值，选题也是一样，过去只能通过输入参考优质文章，或者头脑风暴的方式，已经不是效率最高的方式了。

就拿选题工作流程来说，通过建立自己的问题池、结合AI和框架约束，进行选题分析和衍生，可以给出非常多的优质建议，不但高效还高质量，但是，并不代表一切按照AI来执行，依旧最重要的一环是人的决策判断，通过可靠的过滤标准来做最后一道确认，整体效率和质量会高很多。

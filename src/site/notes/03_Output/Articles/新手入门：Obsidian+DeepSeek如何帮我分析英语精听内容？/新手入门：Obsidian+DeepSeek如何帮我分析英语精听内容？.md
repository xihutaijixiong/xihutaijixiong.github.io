# 标题：新手入门：Obsidian+DeepSeek如何帮我分析英语精听内容？

在完成我的全球订阅输入系统之后，每天都会输入英语优质素材，对于喜欢的内容，会选出来进行英语精听，听写之后，都会记录精听内容标题和文本，以及相关问题，但是当坚持了3个多月，听写了100多篇素材之后，发现遇到了瓶颈，有几个问题一直在我的脑海中纠结。

* 听了哪些：过去听的素材主要是哪些场景
* 覆盖如何：有哪些没有覆盖到大部分生活场景，覆盖了多少工作场景等等
* 难度分布：过去听过的素材难度系数分布是怎么样的

对于这些问题我反复看素材，打标签，但是感觉还是很难有一个系统和量化的评估，因此，开始逐步的来通过Obsidian+DeepSeek来进行赋能，看是否可以帮我解决以上问题，并给出适合我的方案。

## AI Prompt

如果一开始只是知道问题，不知道如何去使用AI来描述需求，不用慌，也可以直接抛出问题，先让DeepSeek给出一个初步的Prompt，比如：
```
每天都会输入英语优质素材，对于喜欢的内容，会选出来进行英语精听，听写之后，都会记录精听内容标题和文本，以及相关问题，但是当坚持了3个多月，听写了100多篇素材之后，发现遇到了瓶颈，有几个问题一直在我的脑海中纠结。

* 听了哪些：过去听的素材主要是哪些场景
* 覆盖如何：有哪些没有覆盖到大部分生活场景，覆盖了多少工作场景等等
* 难度分布：过去听过的素材难度系数分布是怎么样的

对于这些问题我反复看素材，打标签，但是感觉还是很难有一个系统和量化的评估，请给出一个能解决以上问题的Prompt？
```

## AI 分析

基于Prompt 模版确定之后，可以自己进行调整，如下：

```
请基于我当前Obsidian vault中精听文件夹中的素材内容，完成以下三项分析。每项分析请用表格+文字总结呈现。

## 1. 场景覆盖分析
- 列出所有笔记中出现的“场景”标签（或属性中的scene字段），统计每个场景出现的次数。
- 按“生活场景”（如：购物、旅行、餐饮、医疗、社交、娱乐、家庭、教育、交通、天气）和“工作场景”（如：会议、邮件、汇报、谈判、技术讨论、客户沟通、项目管理）两大类归类。
- 输出表格：场景类别 | 具体场景 | 出现次数 | 覆盖状态（已覆盖/未覆盖）
- 最后总结：生活场景覆盖了哪些，缺失了哪些；工作场景覆盖了哪些，缺失了哪些。

## 2. 难度分布分析
- 找出所有笔记中“难度”字段（或属性中的difficulty/level字段），统计每个难度等级（如：初级、中级、中高级、高级、专业级）的笔记数量。
- 输出表格：难度等级 | 笔记数量 | 占比
- 如果笔记中没有明确难度字段，请根据文本长度、词汇复杂度、句式复杂度进行自动推断（分为低、中、高三个等级），并在表格中标注“推断”或“原始”。
- 最后总结：当前难度分布是否合理？是否存在过度集中在某一难度的问题？

## 3. 素材类型与主题分布
- 找出所有笔记中“素材类型”标签（如：新闻、播客、电影片段、TED演讲、日常对话、学术讲座、商务邮件等），统计每种类型的数量。
- 输出表格：素材类型 | 数量 | 占比
- 同时列出每个素材对应的“主题”标签（如：科技、经济、文化、健康、环境、教育、职场等），统计主题分布。
- 最后总结：当前素材类型是否多样化？主题是否覆盖了常见生活和工作领域？

## 输出格式要求
- 所有表格使用GitHub Markdown表格格式。
- 每个分析部分后，用一段话总结关键发现和可操作建议。
- 如果某个字段缺失，请明确说明“未找到该字段”，并给出替代方案（如：从笔记正文中提取关键词推断）。
```
